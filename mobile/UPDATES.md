# Обновление приложения без потери данных

## Как это работает

1. Ты меняешь код (или просишь меня) и загружаешь папку в GitHub. Сборка «Сборка Android» (вкладка Actions) сама собирает приложение и выкладывает его в **Releases** как файл `navigator.apk`.
2. На телефоне: **Настройки → Версия и обновление → Проверить обновление**. Если вышла новая версия, появится кнопка **Обновить**. Раз в сутки приложение проверяет само и показывает плашку на главном экране.
3. Нажимаешь **Обновить** → приложение скачивает файл (с полосой загрузки) → Android показывает окно «Обновить это приложение?» → нажимаешь «Обновить» → открываешь приложение. Все записи, настройки и ключи на месте.

Окно Android с подтверждением обойти нельзя: так устроена система для приложений не из магазина.

## Что защищает данные

- **Один и тот же ключ подписи.** Android ставит новую версию поверх старой, только если подпись совпадает. Поэтому сборка всегда подписывается одним ключом, а номер версии (`versionCode`) растёт сам.
- **Данные лежат отдельно от приложения** (внутри телефона), и при установке поверх не трогаются.
- **Точки восстановления.** Перед каждым обновлением (автоматически, и ещё раз перед установкой) и раз в сутки приложение сохраняет копию всех данных на телефоне. Хранится 4 «обновительных» и 3 ежедневных точки. «Настройки → Точки восстановления → Вернуть». Перед возвратом делается ещё одна точка, так что возврат тоже можно отменить.
- **Версия данных и миграции.** Если когда-нибудь поменяется формат данных, при первом запуске новой версии данные переводятся автоматически (файл `mobile/shim/safety.ts`, список `MIGRATIONS`), а перед этим сохраняется точка. Если перевод не удался, ничего не меняется и приложение сообщает об этом.
- **Защита от старой версии.** Если поставить версию старее, чем данные, приложение ничего не записывает и просит поставить свежую.
- **Точки восстановления не заменяют копию в файле.** Если потерять телефон, они пропадут вместе с ним. Раз в неделю делай копию в «Настройки → Копия данных» и отправляй на Google Диск.

## Единоразовая настройка

### 1. Репозиторий должен быть открытым (Public)
Приложение на телефоне спрашивает GitHub о новых версиях без пароля, а закрытый репозиторий так не открыть. В репозитории нет ничего личного: ни записей, ни ключей (ключи ИИ вводятся уже в приложении). Ключ подписи хранится не в репозитории, а в секретах (шаг 2).

### 2. Добавить ключ подписи
В репозитории: **Settings → Secrets and variables → Actions → New repository secret**
- Name: `NAVIGATOR_KEYSTORE_BASE64`
- Secret: всё содержимое файла `NAVIGATOR_KEYSTORE_BASE64.txt` (одна длинная строка)

**Сохрани файл `NAVIGATOR_KEYSTORE_BASE64.txt` в надёжном месте** (менеджер паролей, Google Диск). Это ключ, которым подписано твоё приложение. Если его потерять, обновлять приложение поверх станет нельзя: придётся удалить старое (вместе с данными, поэтому сначала сделай копию в файл) и поставить новое. Не выкладывай этот файл в репозиторий и никому не отправляй.

### 3. Первая установка
Скачай `navigator.apk` из Releases и установи. Это нужно один раз. Дальше приложение обновляется само по кнопке.

При первом нажатии «Обновить» Android попросит разрешить этому приложению устанавливать обновления (переключатель «Разрешить из этого источника»). Это тоже один раз.

## Выпуск новой версии

1. Подними `version` в `mobile/package.json` (например, `1.19.0`) и допиши раздел в начало `mobile/CHANGELOG.md`: его текст попадёт в «Что нового».
2. Загрузи изменения в GitHub. Сборка запустится сама, через 5–15 минут появится релиз.

## Если что-то не так

- **Сборка красная с сообщением про секрет**: не добавлен `NAVIGATOR_KEYSTORE_BASE64` (шаг 2).
- **Android пишет «Приложение не установлено: конфликт пакетов»**: установленная версия подписана другим ключом (например, собрана до этой настройки). Сделай копию данных в файл, удали приложение, поставь новую версию и восстанови данные из файла. После этого все обновления пойдут поверх.
- **«Релизов пока нет, либо репозиторий закрытый»**: проверь, что репозиторий открытый и сборка завершилась (в Releases есть файл).
- **Нужно вернуть старое состояние данных**: «Настройки → Точки восстановления».
