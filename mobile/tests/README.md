# Проверки приложения для телефона

Три уровня, от быстрых к полным:

1. `npm run check`: поиск необъявленных имён и неверных импортов в коде.
2. `npm run test:tz`: модульные тесты правил приложения (папка `unit/`, vitest) в четырёх часовых поясах. Тесты серверной логики: `node ../scripts/test-tz.mjs backend`.
3. `npm run test:ui`: все браузерные проверки из этой папки. Нужны собранное приложение (`npm run build`) и Playwright с Chromium (`npx playwright install chromium`). Сервер для `dist` поднимается сам.

`npm test` запускает всё подряд. Один файл или несколько по части имени: `node tests/run-all.mjs streak settings`; отдельный файл: `node tests/<имя>.cjs` (нужен свой сервер на порту 8099).

Файл в `tests/` считается проваленным, если код выхода не ноль, в выводе есть «НЕТ», `Error:`, `TimeoutError` или непустой список `ERRORS`. Ответы ИИ, уведомления и погода подменяются, настоящие ключи не нужны. Отладочный вход для тестов: `localStorage["navigator-debug"]="1"`.

В GitHub Actions: workflow «Сборка Android» перед сборкой прогоняет пункты 1 и 2 (если они красные, релиза не будет), workflow «Проверки» запускает пункт 3.

## Основные сценарии
- `ui-flow`: знакомство, подтверждение предложений, задачи, вес, финансы.
- `journal-ai-backup`: запись, предложения, применение, выгрузка и восстановление.
- `onboarding-and-encryption`: знакомство с предложениями, копия с паролем.
- `week-and-evening`: неделя в цифрах и вечерний вопрос. `evening-skip`: вечерний вопрос пропускает день, если запись уже есть.
- `edit-delete`: правка и удаление с подтверждением. `task-deadline`: срок задачи и вкладка «Завтра». `earlier`: «Раньше».
- `new-features`: повтор задач, бюджет, график веса, корзина, журнал ошибок. `recurrence`: повторяющиеся напоминания.
- `home-layout`: «Сегодня» по времени суток, режим «Настроить», кнопка «+». `structure`: нет дублей на «Сегодня» и в «Я».
- `settings-groups`: разделы «Настроек» сворачиваются и запоминают состояние, убранные экраны не открываются.
- `home-tiles-settings`: плитки главного экрана включаются, выключаются и переставляются в «Настройках»; одинокая половинка растягивается.
- `visible-features`: миссия в «Я», сигнал дрейфа в итогах недели, дата портрета, нет симуляции будущего.
- `setup-card`: быстрая настройка (свёрнута в строку, ключ ИИ, «Позже»).

## Дни, серия, неделя
- `daily`: экран «Планы», утренняя сводка и вечерний план. `life-weeks`: недели прожито и впереди.
- `streak-and-date`: серия дней, «сегодня» по местному времени, смена часового пояса.
- `streak-extras`: плитка недели считает вес и привычки, серия заполняет прошлое, пропуск дня, копия пропусков.
- `week-review-and-recurring`: итоги недели, повторы задач, «Я» с серией. `weight-goal`: цель по весу.

## ИИ
- `ai-router` (очередь и паузы), `claude-primary`, `ai-models`, `ai-model-pick`, `ai-fold`, `free-keys`, `pending-ai` (отложенный разбор без ИИ и сети), `secrets` (ключи не попадают в копию и журнал), `bad-settings`.

## Данные и надёжность
- `robustness` (испорченные данные), `scale-and-integrity` (три года данных, плохие копии), `concurrency`, `roundtrip` (полный круг копии), `time-and-forms`, `deep-qa` (вредный и длинный ввод), `offline` (без интернета, Service Worker).
- `update-safety` (версия данных, миграции, точки восстановления), `update-flow` (путь «Обновить» на имитации Android), `final-qa`, `android-plugins` (уведомления, копия и биометрия на имитации плагинов Android).

## Внешний вид
- `design-a4` (скругления и плитки на всех экранах в светлой и тёмной теме), `contrast`, `audit-ui` (размеры нажатий, подписи, прокрутка; 2 флажка задач «мелкие» — ложное срабатывание: область нажатия 48 px), `charts`, `feedback-gestures`, `features-2`, `features-3`, `features-edge`.

## Тесты серверной логики и правил приложения
- `backend/src/__tests__`: модульные тесты на vitest (13 файлов). Базу подменяет заглушка `stubs/prisma.ts`: если тест полезет в базу, он упадёт с понятным сообщением.
- `mobile/unit`: правила серии дней (`streak`), плитки недели (`weekLevels`) и цели по весу (`weightGoal`).
- Новые правила пиши как чистые функции без экрана и хранилища, тогда их легко проверить здесь.
