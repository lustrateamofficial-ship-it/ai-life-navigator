# Проверки приложения для телефона

Нужны Playwright и статический сервер на порту 8099 со сборкой:

    npm run build && (cd dist && python3 -m http.server 8099 &)
    node tests/ui-flow.cjs            # знакомство, подтверждение предложений, задачи, вес, финансы
    node tests/journal-ai-backup.cjs  # запись → предложения → применение → выгрузка → восстановление
    node tests/android-plugins.cjs    # уведомления, копия и биометрия на имитации плагинов Android

Ответ AI в проверках подменяется, настоящие ключи не нужны.
