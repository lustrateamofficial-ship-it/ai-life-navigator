# Навигатор Жизни

Приложение для Android (и установка из браузера), в котором дневник, задачи, цели, вес и привычки лежат на телефоне. Сервера нет: ни Telegram, ни облака, ни базы данных на стороне.

## Устройство

- `mobile/` — само приложение: интерфейс (React), локальная база на телефоне (IndexedDB), оболочка Android (Capacitor), тесты в `mobile/tests`, история версий в `mobile/CHANGELOG.md`.
- `backend/src/` — прикладная логика (маршруты, разбор записей ИИ, подсчёты). Раньше это был сервер; теперь `mobile/build.mjs` встраивает этот код в приложение, подменяя базу данных, Express и окружение лёгкими версиями из `mobile/shim`. Всё остальное, что умеет сам телефон (серия, копии, PDF, уведомления, тема), лежит в `mobile/phone`. Отдельно `backend/` не запускается.
- `backend/prisma/schema.prisma` — описание данных, из него собирается схема для телефона (`mobile/tools/parse-schema.mjs`).
- `DESIGN_PRINCIPLES.md` — принципы дизайна и продукта.
- `.github/workflows/android-apk.yml` — сборка подписанного apk в GitHub Actions, файл появляется в Releases.

## Как обновлять

Распаковать новый архив поверх проекта, сделать Commit/Sync, дождаться сборки во вкладке Actions. На телефоне: Настройки → Версия и обновление → «Обновить». Данные при обновлении не теряются, перед установкой делается точка восстановления. Подробнее: `mobile/UPDATES.md`.

## Проверка

```bash
cd mobile
npm install
npm run build          # собирает dist/
cd dist && python3 -m http.server 8099 &
npm run test:ui        # сценарии в браузере (нужен Playwright)
```

Юнит-тесты логики лежат в `backend/src/__tests__` (vitest, `cd backend && npm install && npm test`).

## Что убрано

Telegram-бот и мини-приложение, сервер на Oracle Cloud (Docker, Caddy, Postgres), расписание рассылок, вход по Telegram, резервное копирование в Google Drive на стороне сервера. Копии теперь делает само приложение: вручную, на Google Диск через «Поделиться» и автоматически раз в неделю в выбранную папку.
